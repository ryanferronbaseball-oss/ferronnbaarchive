# Men's college soccer

Initial pages mirror professional soccer and use a separate match dataset. Seven match results, 22 goal events and 234 appearances are imported. Both credited NCAA assists count toward assists; second credited assists are also shown as a subset. Impact selections are provisional until all cards are verified. Individual goalkeeper data is shown where available, outfield shots and minutes pending. No professional data copied. Portraits, coaches, awards, substitution timelines, global counts, map, yearbook, search and browser QA pending.
