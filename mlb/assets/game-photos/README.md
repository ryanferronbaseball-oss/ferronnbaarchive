# MLB game photos

Upload personal attended-game images here. Preferred names: `YYYY-MM-DD-away-home.jpg` (or `.png`, `.webp`, `.jpeg`); add `-game1`/`-game2` for doubleheaders and `-2`, `-3` for additional photos. Game-page photo integration is pending until files are matched to attended game IDs.

Game pages now load `mlb/data/game_photos.json`, keyed by stable attendance ID. Photos display immediately beneath the scorecard. A single path or array of paths is supported. Uploading a new image does not automatically match it; verify dates and teams before adding registry entries.

Owner-confirmed filename year corrections: `20230724RockiesDodgers.png` belongs to 2003-07-24 (attendance ID 1); `20250728RedsDodgers.png` belongs to 2005-07-28 (attendance ID 2). Both registered using original filenames.
